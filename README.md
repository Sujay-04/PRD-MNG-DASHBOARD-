# 🚀 Productivity Management Dashboard

A modern, feature-rich, and interactive web-based dashboard designed to help you stay focused, organized, and motivated. Built with HTML, CSS, and Vanilla JavaScript, this dashboard serves as your personal command center for daily tasks.

## ✨ Features

* **🌤️ Dynamic Weather & Real-Time Clock:** Check the current weather, temperature, humidity, and wind speed for any city worldwide. Includes a live, real-time clock synced to the searched city's time zone.
* **📝 To-Do List:** Keep track of your daily tasks. Mark them as completed with a single click. (Data persists via LocalStorage).
* **📅 Daily Planner:** An hourly schedule tracker to map out your day efficiently.
* **💡 Motivation Generator:** Get a random inspirational quote with a single click to keep your spirits high.
* **⏳ Pomodoro Timer:** A built-in focus timer featuring a classic 25-minute work session and a 5-minute break system.
* **📌 Daily Goals (Sticky Notes):** A beautiful, interactive corkboard UI featuring pastel-colored sticky notes with realistic tilt and hover animations to pin your top goals.
* **🌗 Dark/Light Mode:** Seamless theme switching for comfortable viewing day or night, with your preference remembered for your next visit.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **APIs Used:** * [WeatherAPI](https://www.weatherapi.com/) (For weather and timezone data)
    * [DummyJSON Quotes API](https://dummyjson.com/docs/quotes) (For random motivation)
* **Icons:** [Remix Icon](https://remixicon.com/)
* **Storage:** Browser LocalStorage (No database required)
